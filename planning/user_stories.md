# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

**Wordle Player**: a user who plays wordle puzzles
**Wordle Creator**: a user who creates and shares unique puzzles for friends to play

## Draft User Stories

1. As a **Wordle Player**, I want to play with new re-inventions on a series of rules I’m familiar with so that I can engage with a game I enjoy in a novel way.
2. As a **Wordle Player**, I want to challenge my friends on the same Wordle puzzles so that we can compete and compare each of our completion times.
3. As a **Wordle Player**, I want to be able to view a list of recently created custom Wordles, so that I can play Wordles made by other players.
4.  As a **Wordle Player**, I want to have the option to create and login into an account with external services (Github, Google, etc), so that I can keep my data secure and not have to separately keep track of my username and password information.
5. As a **Wordle Player**, I want to view my current account's stats, so that I can track all my previous Wordle solves and total games played.
6. As a **Wordle Player**, I want to see a leaderboard of other players' Wordle stats, so that I can see how my skills compare to others and get better at the game.
7. As a **Wordle Creator**, I want to create my own Wordle with custom words, so that I can challenge my other friends to complete my Wordle in the fastest time.
8. As a **Wordle Creator**, I want to be able to edit a custom Wordle, so that I can make changes if I previously made a mistake when creating it.
9. As a **Wordle Creator**, I want to be able to delete my own custom Wordle, so that I can keep my catalogue clean and only share puzzles I am proud of.
10. As a **Wordle Creator**, I want to keep track of all the custom Wordles I have created, so I can manage and store them in one place.
